# Nous deux ♥

Notre app de couple à distance : compte à rebours, mots doux, souvenirs, livre de notre histoire, appel vidéo avec partage d'écran, photobooth, puzzle photo et jeux à deux.

- Site statique (HTML/CSS/JS, sans étape de build), hébergé sur GitHub Pages.
- Données, photos et temps réel : Supabase (`supabase/schema.sql`).
- Appels : WebRTC pair-à-pair, signalisation via Supabase Realtime. Relais TURN optionnel dans Réglages.
